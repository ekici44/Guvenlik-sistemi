# Güvenlik Paneli (telefon uygulaması)

Kişisel güvenlik sisteminin iPhone yönetim paneli. Butonlarla bilgisayara komut gönderir
(durum, test, tuzak aç/kapat, duraklat/devam, bilgisayarı kapat) ve son olayları canlı gösterir.

- Gizli kanal adları bu depoda **yoktur**; telefonda sadece o cihazda saklanır.
- Haberleşme ntfy.sh üzerinden olur; bilgisayardaki `dinleyici.py` komutları alıp cevaplar.
- Anlık bildirimler (telefon kilitliyken) için ntfy uygulaması arka planda "zil" olarak kalır.

Yayın: Settings → Pages → Branch: `main` / `(root)`.
